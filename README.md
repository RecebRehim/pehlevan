# Impossible — Physical Challenge Lab

A cinematic browser-based physical challenge experience built with Next.js, React Three Fiber, and Three.js.

## Challenges

1. **Break it** — punch a watermelon until the top half splits away.
2. **Bend it** — drag rebar around the strongman's arm.
3. **Lift it** — raise a sedan until the rear wheels clear the ground.
4. **Hammer it** — drive a rod through three steel boxes.

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```
